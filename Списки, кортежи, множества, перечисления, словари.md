
Список - упорядоченная изменяемая коллекция элементов
`empty_list = []`

Основные операции:
- Доступ по индексу
- Изменение элементов
- Добавление и удаление элементов
- Сортировка

Методы:
*Добавление элементов*
.append - добавление элемента в конец
.insert - вставка элемента на позицию
*Удаление элементов*
.remove - удаление по значению
.pop - удаление по индексу
*Другие методы*
.sort - сортировка
.reverse - обратная сортировка


Кортеж - неизменяемая упорядоченная коллекция элементов
`empty_tuple = ()`

Особенности:
- Невозможно изменять элементы
- Более эффективное использование памяти
- Можно использовать как ключи в словарях


Множество - неупорядоченная коллекция уникальных элементов
`empty_set = set()`
`filled_set = {1, 2, 3, 5}`


Перечисления - набор именованных констант
`from enum import Enum`
`class Color(Enum):`
	`RED = 1`
	`GREEN = 2`
	`BLUE = 3`


Словарь - коллекция пар ключ-значение
`empty_dict = {}`
`filled_dict = {`
	"key1": "value"
	"key2": 23
	"key3": "somthing else"
`}`

Основные операции:

*Доступ к значениям*
print(filled_dict["key2"]) *23*

*Добавление/изменение*
filled_dict['key4'] = 2
filled_dict['key1] = 'value2'

*Удаление*
del filled_dict['key1']
