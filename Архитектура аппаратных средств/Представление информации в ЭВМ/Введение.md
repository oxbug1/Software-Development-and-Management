- Толстая линия - информация

#### Минимальный набор функциональных блоков для ЭВМ

- АЛУ - блок для выполнения арифметических и логических операций

- ЗУ - блок для хранения информации

- Устройство для ввода (Увв) и вывода (Увыв) информации

- УУ - Устройство управления. Указывает в какое время и когда другим устройствам выполнять необходимые действия.

УУ инициирует работу Увв, давая ему команду на выполнение операции ввода информации в ЗУ, а также указывает из какого места ЗУ необходимо передать информацию в АЛУ, какую операцию над этой информацией должно выполнить АЛУ, и в какое место ЗУ нужно записать результат операции. УУ инициирует работу Увыв, для вывода результата из ЗУ и выполняет ряд друих операций.
