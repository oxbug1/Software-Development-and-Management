# 3. Основы HTML. Работа с текстом. Заголовки

## HTML-текст

HTML-текст представлен в спецификации тегами для форматирования и группировки текста. Теги же представляют собой контейнеры для текста и не имеют визуального отображения.

Грамотно отформатированный текст дает понять поисковым системам, какие слова несут важную смысловую нагрузку, по каким из них предпочтительно ранжировать веб-страницу в поисковой выдаче.

## Теги заголовков

Теги <h1>...<h6> используются **только для заголовков и подзаголовков**. Вложение других тегов в теги <h1>...<h6> **не допускается**. 

## Теги для форматирования текста

| Тег      | Описание                                                                                                                                                 |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <b>      | Задаёт полужирное начертания шрифта. Выделяет текст без акцента на его важность. Для тега доступны глобальные атрибуты                                   |
| <em>     | Отображает шрифт курсивом, придавая тексту значимость. Для тега доступны глобальные атрибуты                                                             |
| <i>      | Отображает шрифт курсивом. Для тега доступны глобальные атрибуты.                                                                                        |
| <small>  | Уменьшает размер шрифта на единицу по отношению к обычному тексту. Для тега доступны глобальные атрибуты.                                                |
| <strong> | Задаёт полужирное начертание шрифта, относится к тегам логической разметки, указывая браузеру на важность текста. Для тега доступны глобальные атрибуты. |
| <sub>    | Используется для создания нижних индексов. Сдвигает текст ниже уровня строки, уменьшая его размер. Для тега доступны глобальные атрибуты                 |
| <sup>    | Используется для создания степеней. Сдвигает текст выше уровня строки, уменьшая его размер. Для тега доступны глобальные атрибуты                        |
| <ins>    | Выделяет текст в новой версии документа, подчёркивая его. Для тега доступны следующие атрибуты: cite , datetime                                          |
| <del>    | Перечёркивает текст. Используется для выделения текста, удаленного из документа. Для тега доступны следующие атрибуты: cite , datetime                   |
| <mark>   | Применяется для выделения фрагментов текста в справочных целях, окрашивая блок символов желтым цветом. Для тега доступны глобальные атрибуты             |

## Абзацы, средства переноса текста

| Тег  | Описание                                                                                                                                                                                                                                 |
| ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <p>  | Разбивает текст на отдельные абзацы, отделяя друг от друга пустой строкой. Браузер автоматически добавляет верхний и нижний отступ, равный 1em , при этом отступы соседних абзацев «схлопываются». Для тега доступны глобальные атрибуты |
| <br> | Переносит текст на следующую строку, создавая разрыв строки. Для тега доступны глобальные атрибуты.                                                                                                                                      |
| <hr> | Используется для разделения контента на веб-странице. Отображается в виде горизонтальной линии. Для тега доступны глобальные атрибуты.                                                                                                   |
