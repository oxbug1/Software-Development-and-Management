## Групповые селекторы

Указываются через запятую, например:

```css
h1, h2, .test, #test {
    color: blue;
}
```

## Универсальный селектор

Селектор * позволяет выбрать все элементы внутри документа.

Также может использоваться для выбора всех элементов внутри тега, например:

```css
div * {
            color: rgb(50, 100, 150);
            font-style: italic;
        } - выберет все элементы внутри блока <div>
```

## Псевдоэлементы

Наиболее расспространненые из них это:

- ::first-letter - позволяет создавать инициал (буквицу) — начальный символ
  текстового блока. 

- ::first-line - позволяет стилизовать первую строку абзаца, которая будет
  отличаться.

- ::before - добавляет определённое содержимое перед каждым указанным
  элементом.

- ::after - добавляет определённое содержимое после каждого указанного
  элемента.

## Псевдоклассы

- :focus производит выбор элементов, которые в настоящий момент находятся
  в фокусе (допускается использовать на элементы, которые принимают события клавиатуры или другие данные)

- :link адаёт стиль всем ссылкам, по которым пользователь не произвёл
  переход (не посещенные ссылки). Как правило, используется с псевдоклассом :visited, который определяет стиль для посещенных пользователем ссылок.

- :active используется для выбора активного элемента - элемента на который в
  данный момент пользователь кликнул мышкой. Стиль для элемента применится и будет работать пока удерживается кнопка мыши

- :hover используется практически на каждой странице любого сайта, нужен для стилизации любого элемента, на который в данный момент указывает курсор мыши. Чаще всего используют данный псевдокласс с ссылками, кнопками, в меню навигации и таблицами

## Селекторы атрибута и псевдоклассы отрицания дочерних элементов

```css
img[title] {
    выбирает все элементы img в которых есть атрибут title
}
```

### Псевдокласс отрицания :not()

**:not()** - позволяет выбрать элементы, или селекторы
отличные от указанных.

**Что <u>нельзя</u> использовать с псевдоклассом :not()**

- Использовать в одном селекторе несколько псевдоклассов :not()

- Использовать :not() с псевдоэлементами

- Использовать с селекторами потомков

- Использовать в групповых селекторах

## Селектор дочерних элементов

```css
p > a {
    выбирает любой элемент <a> дочерний по отношению к <p>
}
```

## Псевдоклассы дочерних элементов

:first-child и :last-child - выбирают первого и последнего потомка соответсвтвенно например:

```html
<style>
    h1:first-child {
        color: red;
    }
    h1:last-child {
        color: green;
    }
</style>
<body>
    <h1>
    <h1>
    <h1>
</body>
```

**Псевдокласс :nth-child**() - Стилизация по порядковому номеру. Позволяет выбрать  

элемент по его пордковому номеру или продвинуто четные или нечетные числа и заданные по элементарной математической формуле.

## Селекторы типов дочерних элементов, смежных элементов, следующих элементов

**Селекторы типов дочерних элементов**

**:first-of-type** - применяет заданный стиль к элементу, который является
первым дочерним элементом, определенного типа внутри родительского элемента.

**:nth-of-type** - выбирает каждый указанный элемент определенного типа,
который является дочерним элементом своего родительского элемента.



## Селектор смежных элементов

```сss
h2~p {
    все элементы p смежные (сестринские) для h2
}

div~* {
    Все элементы смежные для div
}
```
