# Каскадные таблицы стилей (CSS). Виды селекторов



CSS - Каскадные таблицы стилей. Используются для создания и изменения стиля элементов, веб-страниц и пользовательских интерфейсов написанных на языках HTML и XHTML, также могут быть применены к любому виду XML-документа, в том числе XML, SVG и XUL, отделяя стиль представления от содержимого документов. CSS упрощает создание веб-страниц и обслуживание сайтов.

CSS поддерживает таблицы стилей для конкретных носителей, поэтому вторы могут адаптировать представление своих документов к:

- Визуальным браузерам

- Слуховым устройствам

- Принтерам

- Брайлевским устройствам

- Карманным устройствам и т.д.

Каскадные таблицы стилей *описывают правила форматирования* элементов с помощью **свойств** и **допустимых значений** для этих свойств. Для каждого элемента можно использовать *ограниченный набор* свойств, стальные свойства **не будут** оказывать никакого влияния.

Объявление стиля состоит из двух частей: **Селектора** и **{обявления}**. Имена элементов не чувствительны к регистру, поэтому h1 и H1 работают одинаково. Объявление состоит из двух частей: *имя свойства:* (например: color) и *значения;* (например: gray), например: h1 {color: gray;}. Селектор сообщает браузеру, какой именно элемент форматировать, а в блоке объявления перечисляются форматирующие команды - свойства и их значения. Так как CSS это таблицы стилей они могут объединяться, в сочетании с другими таблицами стилей, правило будет определять окончательное представление документа.

## Виды таблиц стилей

**Внешняя таблица стилей**

Представляет собой текстовый файл с расширением **.css**, в которм находится набор CSS-стилей элементов. Подключается к веб-странице с помощьютега **<link>**, распооженного внутри раздела <head>. Такие стили работают для всех страниц сайта. К каждой странице можно подсоединить несколько таблиц стилей добавляя последовательно несколько тегов <link>, указав в атрибуте тега media назначение данной таблицы стилей.
rel="stylesheet" - указывает на тип сслыки (ссылка на таблицу стилей)

```html
<head>
    <link rel="stylesheet" href="css/style.css">
    <link rel="stylesheet" href="css/style.css" media="all">
</head>
```

В HTML5 атрибут **type"text/css"** не является обязательным и задается по умолчанию.

**Внутренние стили**

Встраиваются в раздел <head> HTML-документа и определяются внутри тега <style>. *Внутренние* стили имеют приоритет над *внешними* но уступают *встроенным* стилям.

```html
<head>
    <style>
        h1,h2 {
            color: red;
            font-family: "Times New Roman", Georgia, Serif;
            line-height: 1.3em;
        }
    </style>
</head>
```

**Встроенные стили**

Встраиваются непосредственно внутрь тега элемента с помощью атрибута style

```html
<body>
    <p style="font-weight: bold; color: red;">Hello World!</p>
</body>
```

## Виды селекторов

Селекторы представяют структуру веб-страницы. Селекторами могут быть:

- Элементы

- Классы элементов

- Идентификаторы элементов

- Псевдоклассы

- Псевдоэлементы

**Универсальный селектор**

Соответствует любому HTML-элементу. Также селектор может использоваться в комбинации с псевдоклассом или псевдоэлементом

```css
* {margin: 0;} - обнулит внешние отступы для всех элементов сайта
*:after {css-стили;}
*:checked {css-стили;}
```

**Селектор элемента**

Селекторы элементов позволяют форматировать все элементы данного типа на всех страницах сайта.

```css
h1 {font-family: Lobster, cursive;}
```

**Селектор класса**

Позволяют задавать стили для одного и более элементов с одинаковым именем класса, расположенных в разных местах страницы или на разных страницах сайта.

```css
.headline {
    text-transform: uppercase;
    color: light-blue;
}
```

Если элемент имеет несколько атрибутов класса, их значения объединяются с пробелами.

```html
<h1 class="headline post-title">какой-то заголовок</h1>
```

**Селектор идентификатора**

Позволяет форматировать один конкретный элемент

```css
#sidebar {
    width: 300px;
    float: left;
}
```

**Селектор потомка**

Селекторы потомков применяют стили к элементам, расположенным внутри элемента контейнера. Например:

```css
ul li {
    text-transform: uppercase;
} - выберет все элементы li являющихся потомками всех элементов ul
```

Если нужно офтформатировать потомки определенного элемента, этому элементу нужно задать стилевой класс:

```css
p.first a {
    color: green;
} - данный стиль применится ко всем ссылкам, 
потомкам абзаца(<p>) с классом first

p .first a {
    color: green;
} - если добавить пробел, то будут стилизованы сслыки, 
расположенные внутри любого тега класса first, 
который является потомком элемента <p>

.first a {
    color: green;
} - данный стиль применится к любой ссылке, 
расположенной внутри данного элемента,
обозначенного классом .first
```

**Дочерний селектор**

У одного элемента может быть несколько дочерних элементов и только один родительский. Дочерний селектор позволит применить стили только если дочерний элемент идет сразу за родительским элементом и дочерний элемент больше ни во что не вложен.

**Сестринский селектор**

Сестринские отношения возникают между элементами, имеющими общего родителя.

*h1 + p* - выберет все первые абзацы, идущие непосредственно за любым тегом <h1>, не затрагивая остальные абзацы

*h1 ~ p* - выберет все абзацы, являющиеся сестринскими по отошению к любому заголовку h1 и идущие сразу после него 

**Селектор атрибута**

Селекторы атрибутов выбирают элементы на основе имени атрибута или значения атрибута:

- [атрибут] - все элементы содержащие указанный атрибут.

- [alt] - все элементы для которых задан атрибут alt

- селектор[атрибут] - элементы данного типа, содержащие указанный атрибут, img[alt] - только картинки с атрибутом alt

- селектор[атрибут="значение"] - элементы данного типа, содержащие указанный атрибут с конкретным значением, img[title="flower"] - все картинки содержащие атрибут title со значением flower

- селектор[атрибут~="значение"] - элементы частично содержащие данное значение, например, если для элемента задано несколько классов через пробел, p[class~="feature"] - абзацы, имя класса котрых содержит feature

- селектор[атрибут|="значение"] - элементы, список значений атрибута которых начинается с указанного слова, p[class|="feature"] - абзацы, имя которых feature или начинается на feature

- селектор[атрибут^="значение"] - элементы, значение которых начинается с указанного значения, a[href^="http://"] - все ссылки начинающиеся с http://

- селектор[атрибутзнакдолара="значение"] - элементы, значение атрибута которых заканчивается указанным значением, img[src$=".png"] - все картинки в формате .png

- селектор[атрибут*="значение"] - элементы, значение атрибута которых содержит в любом месте указанное слово, a[href*="book"] - все ссылки название которых содержит book

**Селектор псевдокласса**

Псевдоклассы - классы фактически не приклепленные к HTML тегам. Они позволяют применить CSS-правила к элементам при совершении события или подчиняющимся определенному правилу. Псевдоклассы характеризуют элементы со следующими свойствами:

- :link — не посещенная ссылка;

- :visited — посещенная ссылка;

- :hover — любой элемент, по которому проводят курсором мыши;

- :focus — интерактивный элемент, к которому перешли с помощью клавиатуры или
  активировали посредством мыши;

- :active — элемент, который был активизирован пользователем;

- :valid — поля формы, содержимое которых прошло проверку в браузере на соответствие
  указанному типу данных;

- :invalid — поля формы, содержимое которых не соответствует указанному типу данных;

- :enabled — все активные поля форм;

- :disabled — заблокированные поля форм, т.е., находящиеся в неактивном состоянии;

- :in-range — поля формы, значения которых находятся в заданном диапазоне;

- :out-of-range — поля формы, значения которых не входят в установленный диапазон;

- :lang() — элементы с текстом на указанном языке;

- :not(селектор) — элементы, которые не содержат указанный селектор — класс,
  идентификатор, название или тип поля формы — :not([type="submit"]) ;

- :target — элемент с символом # , на который ссылаются в документе;

- :checked — выделенные (выбранные пользователем) элементы формы.

**Селектор структурных псевдоклассов**

Структурные псевдоклассы отбирают дочерние элементы в соответствии с параметром, указанным в круглых скобках:

- :nth-child(odd) — нечётные дочерние элементы;

- :nth-child(even) — чётные дочерние элементы;

- :nth-child(3n) — каждый третий элемент среди дочерних;

- :nth-child(3n+2) — выбирает каждый третий элемент, начиная со второго дочернего
  элемента (+2) ;

- :nth-child(n+2) — выбирает все элементы, начиная со второго;

- :nth-child(3) — выбирает третий дочерний элемент;

- :nth-last-child() — в списке дочерних элементов выбирает элемент с указанным
  местоположением, аналогично с :nth-child() , но начиная с последнего, в обратную сторону;

- :first-child — позволяет оформить только самый первый дочерний элемент тега;

- :last-child — позволяет форматировать последний дочерний элемент тега;

- :only-child — выбирает элемент, являющийся единственным дочерним элементом;

- :empty — выбирает элементы, у которых нет дочерних элементов;

- :root — выбирает элемент, являющийся корневым в документе — элемент html .

**Селекторы псевдоэлемента**

Псевдоэлементы используются для добавления содержимого, которое генирируется с помощью свойства content:

- :first-letter — выбирает первую букву каждого абзаца, применяется только к блочным элементам;

- :first-line — выбирает первую строку текста элемента, применяется только к блочным элементам;

- :before — вставляет генерируемое содержимое перед элементом;

- :after — добавляет генерируемое содержимое после элемента.

## Комбинация селекторов

Для более точного отбора элементов для форматирования можно использовать комбинации селекторов.

a[href][title] - выберет все ссылки ля которых заданы атрибуты href и title

img[alt*="css"]:nth-of-type(even) - выберет все четные картинки, альтернативный текст которых содержит слово css.

## Группировка селекторов

Один и тот же стиль можно одновременно применить к нескольким элементам. Для этого необходимо в левой части объявления перечислить через запятую нужные селекторы:

```css
h1,h2,p,span {
    color: tomato;
    background: white;
}
```
