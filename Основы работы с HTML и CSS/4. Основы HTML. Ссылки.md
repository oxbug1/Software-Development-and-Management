# 4. Основы HTML. Ссылки

## HTML-сслылки

Ссылки представляют собой связь между двумя ресурсами, один из которых текущий документ. Ссылки содаются с помощью тегов <a>, <area>, <link>

Существует 2 категории ссылок:

- Ссылки на внешние ресурсы - <link>. Используется для расширения возможностей  текущего документа при обработке браузером.

- Гиперссылки - сылки на другие ресурсы, которые пользователь может посетить или загрузить.

### Структура ссыки

Ссылка состоит из двух частей - **Указателя**(фрагмент текста или изображение видимые пользователям) и **адресной части** (адрес ресурска к которому необходимо перейти).

Адресная часть URL(Uniform Resource Locator) - унифицированный адрес ресурса. При создании адресов **рекомендуется использовать дефис**, а не символ подчеркивания.

```html
//Ссылка в корневую папку из index.html
<a href="termin.html">Ссылка на объект в корневой папке</a>
//Ссылка в дочерню папку из index.html
<a href="author/author.html">Ссылка на объект в дочерней папке</a>
//Ссылка в родительскую папку из дочерней папки
<a href="../index.html">Ссылка в родительскую папку на главный объект</a>
```

### Якоря

Якоря - внутренние ссылки, которые создают переходы между разделами. Реализуется также как ссылка в теге <a> с услвием что в нутри атрибута href, перед именем указателя ставится знак #. Прим:

```html
<h1>Времена года</h1>
<a href="#p1">Лето</a>
<a href="#p2">Осень</a>
<a href="#p3">Зима</a>
<a href="#p4">Весна</a>
<p id="p1">Описание Лета</p>
<p id="p2">Описание Осени</p>
<p id="p3">Описание Зимы</p>
<p id="p4">Описание Весны</p>
```
