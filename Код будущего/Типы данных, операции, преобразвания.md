## Типы данных

- Простые: числа, строки

- Коллекции: списки, кортежи, словари

- Остальные: файлы, итераторы, сокеты, NAN

### Числовые типы

- int

- float

- complex (комплексные числа): Представляют числа вида a + bi, a и b - действительные числа, i - мнимая единица

### Строковый тип

- str

### Логический тип

- bool

### Типы коллекций

- list (список) - изменяемая упорядоченная последовательность элементов, которая может содержать элементы различных типов данных:  [1, "текст", 3.14]

- tuple (кортеж) -  неизменяемая упорядоченная последовательность
  элементов, похожая на список, но элементы после создания изменить
  нельзя: (1, "текст", 3.14)

- dict (словарь) - изменяемая неупорядоченная коллекция данных,
  хранящаяся в виде пар «ключ-значение»

- set (множество) - изменяемая неупорядоченная коллекция уникальных
  элементов.

### Бинарный типы

- bytes - неизменяемая последовательность байтов

- bytearray - изменяемая последовательность байтов

- позволяет работать с памятью как с
  последовательностью байтов, полезно для больших объёмов
  данных

### Другие типы

- NoneType: представляет отсутствие значения, а сам объект
  None является единственным экземпляром этого типа
