А

1. Алгоритм — последовательность действий для решения задачи за конечное число шагов. 2. API (Application Programming Interface) — интерфейс взаимодействия между программами, набор функций и процедур для обмена данными. На верх

Б

1. Баг (bug) — ошибка в программе, приводящая к некорректной работе. 2. Бит — минимальная единица информации (0 или 1). На верх

В

1. Вирус — вредоносная программа, способная внедряться в код других программ и распространяться. 2. Веб‑браузер — приложение для просмотра веб‑страниц (например, Chrome, Firefox). На верх

Г

1. Гигабайт (ГБ) — единица измерения объёма данных, равная 1 073 741 824 байтам (2³⁰). 2. Графический интерфейс (GUI, Graphical User Interface) — способ взаимодействия пользователя с системой через визуальные элементы (кнопки, меню). На верх

Д

1. Данные — зарегистрированные сигналы, факты, числа, текст, которые могут быть обработаны компьютером. 2. Домен — имя сайта в сети (например, example.com). На верх

Е

1. Е‑мейл (e‑mail, электронная почта) — система обмена сообщениями через сеть. 2. Единицы измерения информации — биты, байты, килобайты и т. д., используемые для количественной оценки данных. На верх

Ё

На верх

Ж

1. Железо (жаргон) — аппаратное обеспечение компьютера (процессоры, платы, диски). 2. Жизненный цикл ПО — этапы существования программного продукта: анализ, проектирование, разработка, тестирование, эксплуатация, сопровождение, вывод из эксплуатации. На верх

З

1. Заглушка — временный код или ресурс, имитирующий работу недостающего компонента. 2. Запрос (в БД) — инструкция для извлечения, изменения или удаления данных из базы (например, SQL‑запрос). На верх

И

1. Интерфейс — точка взаимодействия между системами, программами или пользователем и программой. 2. Интернет — глобальная компьютерная сеть, объединяющая миллионы устройств. На верх

К

1. Код — текст программы на языке программирования. 2. Кэш — временное хранилище данных для ускорения доступа к ним (например, кэш браузера). На верх

Л

1. Логин — имя пользователя для входа в систему. 2. Локальная сеть (LAN, Local Area Network) — сеть, объединяющая компьютеры в пределах одного помещения или организации. На верх

М

1. Массив — структура данных, хранящая набор элементов одного типа под индексами. 2. Модуль — отдельный компонент программы, выполняющий конкретную функцию. На верх

Н

1. Носитель информации — физическое устройство для хранения данных (жёсткий диск, флеш‑карта). 2. Навигация по веб‑узлам — это система средств и механизмов, позволяющих пользователю перемещаться между различными разделами, страницами и элементами веб‑сайта (веб‑узла) с целью поиска и получения нужной информации. На верх

О

1. Операционная система (ОС) — программное обеспечение, управляющее ресурсами компьютера (Windows, Linux, macOS). 2. Оптимизация — улучшение производительности или эффективности кода, алгоритма, системы. На верх

П

1. Программа — набор инструкций для выполнения определённой задачи на компьютере. 2. Протокол — набор правил и форматов для обмена данными в сети (например, HTTP, TCP/IP). На верх

Р

1. Разметка (например, HTML) — язык описания структуры и оформления веб‑страниц. 2. Резервное копирование — создание копий данных для восстановления в случае потери. Скрипт — небольшой программный код, автоматизирующий задачи (например, JavaScript‑скрипт). Т 1. Технология — совокупность методов, процессов и инструментов для решения задач (например, блокчейн, облачные технологии). 2. Трафик — объём данных, передаваемых через сеть за определённый период. У 1. Устройство — аппаратный компонент компьютера или сети (процессор, роутер, принтер). 2. Уязвимость — слабое место в системе, которое может быть использовано для атаки. Ф 1. Файл — именованная область данных на носителе (текст, изображение, программа). 2. Фреймворк — готовая структура и набор инструментов для разработки ПО (например, Django, React). Х 1. Хост (host) — устройство или программа, предоставляющая сервисы в сети (сервер, компьютер пользователя). 2. Хэш (hash) — результат преобразования данных алгоритмом хеширования (используется для проверки целостности, паролей). Ц 1. Цикл — конструкция в программировании для многократного выполнения блока кода. 2. Цифровая подпись — криптографический механизм подтверждения подлинности и целостности электронного документа. Ч 1. Чип — микросхема, выполняющая вычислительные или управляющие функции (процессор, память). 2. Чат — средство онлайн‑общения в реальном времени. Ш 1. Шина — набор проводников для передачи данных между компонентами компьютера (системная шина, PCI). 2. Шифрование — преобразование данных в зашифрованную форму для защиты от несанкционированного доступа. Э 1. Экран — устройство вывода графической и текстовой информации (монитор, дисплей). 2. Эмулятор — программа или устройство, имитирующее работу другой системы (например, эмулятор Android). Ю 1. Юзер (жаргон, от user) — пользователь компьютера или сервиса. 2. Юзабилити (usability) — удобство и простота использования интерфейса. Я 1. Язык программирования — формальный язык для записи алгоритмов (Python, Java, C++). 2. Ядро (kernel) — основной компонент ОС, управляющий процессами, памятью и устройствами.
