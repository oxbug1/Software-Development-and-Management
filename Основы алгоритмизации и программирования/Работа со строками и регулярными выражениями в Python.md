### Операции над строками:

- Конкатенация - склеивание строк
```
a = 'Hello '
b = 'World!'
print(a + b) # Hello World!
```
- Дублирование - умножение строки повторяет ее заданное кол-во раз
```
c = 'Hi' * 3
print(c) # HiHiHi
```
- Доступ к символам
```
d = 'Python'
print(d[0]) # P
print(d[-1]) # n
```
- Извлечение частей строки выполняется с помощью срезов.
```
print(d[:3]) # Pyt || Срез трех символов справа
print(d[2:]) # thon || Срез двух символов слева
```
### Методы строк:

- len() - возвращает длину строки
- upper(), lower() - преобразуют строку в верхний или нижний регистр
- strip() - удаляет пробелы с начала и конца строки
- split() - разбивает строку на список по разделению
- join() - Объединяет элементы списка в единую строку
- replace() - Замещает указанную подстроку другой
- startswitch() - Проверяет начало строки на заданную подстроку
- endswitch() - Проверяет конец строки на заданную подстроку
- find() - Возвращает индекс первого вхождения подстроки
### Регулярные выражения
Регулярное выражение (regex) - это шаблон для поиска последовательности символов внутри строки. Для работы с ними используется страндартная библиотека re.
Простые варианты записи регулярных выражений:
- . - Любой одиночный символ, кроме перевода строки
- \\\*- Повтор предыдущего элемента ноль или больше раз
- + - Повтор предыдущего элемента хотя бы один раз
- ^ - Начало строки
- $ - Конец строки
- \[abc] - один из указанных символов
- \[^abc] - любой символ кроме указанных 
Методы модуля re:
- search(pattern, string) - Ищет первое совпадение
- match(pattern, string) - Проверяет совпадение с началом строки
- findall(pattern, string) - Находит все совпадения
- sub(pattern, repl, string) - Заменяет найденные совпадения новым текстом
