## Введение в структурное программирование

Структурное программирование - методалогия для разработки программного обеспечения, ориентированная на построение упорядоченной и хорошо организованной структуры программы.

Ключевая идея в том чтобы представить сложную задачу как совокупность небольших, отностительно самостоятельных модулей, каждый из которых реализует какую-то простую подзадачу, которая как правило решается посредством применения базовых управляющих конструкций: линейная, ветвление и цикл.

### Принцип декомпозиции задач

Декомпозиция задач - принцип разделения большой и сложной задачи на ряд мелких, более управляемых подзадач. Повышает прозрачность проекта и снижает сложность восприятия программы.

Основная цель декомпозиции - упрощение разработки, разложив общую задачу на этапы, которые проще реализовать и проверить. Каждый этап реализуется отдельным модулем или функцией, которые затем объединяются в единое целое.

Пример:

Разработать программу расчета средней оценки студента по предметам.

Шаги декомпозиции:

- Ввод данных: список оценок студента

- Расчет общей суммы оценок

- Подсчет колличества предметов

- Определение среднего значения

- Форматирование результата

- Вывод результата

Пример 2:

Разработка веб-приложения для учета доходов и расходов.

Ключевые задачи:

- Авторизация пользователя
  
  - Авторизация проверяет введенные данные и создает сессию

- Добавление записей о доходах и расходах
  
  - Добавление записи предполагает ввод суммы, категории, комментария и сохранение данных в базу

- Просмотр статистики
  
  - Просмотр статистики объединяет чтение данных из базы и отображение графиков

- Экспорт данных
  
  - Экспорт формирует файл CSV или PDF с отчетом

Такой подход обоеспечивает: 

- Модульность и расширяемость приложения, делая разработку легче контролируемой. 

- Уменьшает вероятность появления багов, поскольку каждая небольшая задача тестируется отдельно. 

- Код становится легким для понимания и чтения. 

- Повторное использование готовых решений упрощается. 

- Сокращаются затраты на поддержку и модификацию программ.
