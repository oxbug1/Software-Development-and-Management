# Возможные подходы к классификации языков программирования

- По уровню абстракции:
  Низкоуровневые языки - близко соответствуют аппаратному обеспечению компьютера, требуют детального знания архитектуры устройства. | Ассемблер.
  Высокоуровневые языки - позволяют разрабатывать приложения независимо от особенностей конкретного оборудования, используют абстрактные конструкции. | Python, С++, Java, JavaScript, C#, Kotlin, PHP, Ruby, Golang (Go) и другие.

- По принципу реализации:
  Интерпретируемые языки - программа выполняется построчно, без предварительной трансляции в машинный код. Это удобно для быстрой проверки небольших фрагментов кода. | Python, Ruby, Perl
  Компилируемые языки - исходный код преобразующийся в исполняемый файл перед выполнением. Такой подход обеспечивает высокую скорость выполнения, но требует больше ресурсов на этапе сборки проекта. | C++, Go, Rust

- По типу обработки данных:
  Статически типизированные языки - типы переменных проверяются на этапе компиляции | Java, C#, Haskell
  Динамически типизированные языки - проверка типов производится во время выполнения программы. | Python, JavaScript, Ruby

- По стилю программирования:
  Процедурные языки - организация программы вокруг функций и инструкций. Основная идея заключается в последовательном выполнении шагов алгоритма (системное программирование). | Fortan, C
  Объектно-ринтированные языки - акцент делается на объектах и классах, позволяющих организовать код в виде иерархической структуры. | Python, Java, C++, C#
  Функциональные языки - основной упор сделан на использование чистых функций, отсутствие побочных эффектов и неизменяемость данных. | Lisp, Haskell, Erlang.
  Логическое программирование - основанное на построении формальных утверждений и выводов на их основе | Prolog

- По области применения:
  Научные вычисления - языки оптимизированные для численных расчетов и анализа данных. | Mathlab, Julia, R
  Бизнес-приложения - поддержка сложных операций с большими объемами данных и транзакциями. | COBOL, SQL
  Интернет технологии - разработка веб-интерфейсов и серверных решений. | HTML/CSS, JavaScript, PHP, ASP.NET
  Система реального времени - управление устройствами и системами, критичными ко времени отклика. | Ada, Lua
